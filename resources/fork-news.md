# Vix's OpenFront

An independently hosted fork of OpenFront.

- Play solo or invite friends to private lobbies. Guests can join without an account.
- Create an account to save achievements and unlock cosmetics with Caps earned by playing.
- Try the custom Viktor and tpg maps.
- Enjoy the purple theme with readable combat indicators.

[Source code and updates](https://github.com/ViktorP04/OpenFront)
